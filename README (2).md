# Campus Food Hub

> **Fuel your day. Browse cafeteria menus, save meals, and build sample orders.**

A clean, responsive single-page web app designed for students to explore campus dining options, check prices, save favorite meals, and build hypothetical sample orders.

## 🚀 Features

- **Cafeteria Menu Explorer**: Search and filter meals by cafeteria locations (*Main Hall*, *North Diner*, *Tech Cafe*).
- **Prices & Item Details**: View updated prices, meal categories, and location tags.
- **Save Favorite Meals**: One-click star icon to bookmark favorite meals saved directly to LocalStorage.
- **Sample Order Builder**: Add items to a virtual tray, adjust quantities, calculate live total costs, and preview order summaries.
- **Local Persistence**: Saves your bookmarked meals and active sample order in your browser's local storage.

## 🛠️ Step-by-Step Guide to Publish on GitHub Pages

Follow these simple steps to host this web application for free on GitHub Pages:

### Step 1: Create a GitHub Repository
1. Log in to your [GitHub Account](https://github.com/).
2. Click the **+** icon in the top right corner and select **New repository**.
3. Name your repository (e.g., `campus-food-hub`).
4. Set visibility to **Public**.
5. Click **Create repository**.

### Step 2: Upload Files
1. Click the **uploading an existing file** link on your repository page.
2. Drag and drop `index.html` (and `README.md`) into the GitHub interface.
3. Scroll down and click **Commit changes**.

### Step 3: Turn On GitHub Pages
1. In your repository, click the **Settings** tab at the top.
2. In the left navigation menu, click **Pages** (under *Code and automation*).
3. Under **Build and deployment** -> **Branch**, select `main` (or `master`) from the dropdown.
4. Keep folder set to `/ (root)` and click **Save**.
5. Wait 1 to 2 minutes. GitHub will provide your live website link:
   `https://<your-username>.github.io/campus-food-hub/`
